# FlowBudget

Free personal finance tracker — track spending, set budgets, visualize trends.

## Setup

1. Rename `.env.local.example` to `.env.local` and add your Supabase keys
2. Run `npm install`
3. Run Supabase schema from `supabase-schema.sql` in Supabase SQL Editor
4. Run `npm run dev`

## Deploy to Vercel
Push to GitHub, import on Vercel, add env vars, deploy.

## AdSense
After approval, edit `src/components/ui/AdSenseSlot.tsx` and uncomment the `<ins>` block with your real publisher/slot IDs.
